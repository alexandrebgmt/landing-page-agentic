# PIPELINE DE VÍDEO & CONSISTÊNCIA DE PERSONAGENS

## 1. Regra de Ouro da Consistência
- Criar sempre a "Imagem Mestra" (Master Reference) do personagem antes das cenas.
- Usar a imagem aprovada como ponto de partida (Image-to-Video) para evitar mutações.

## 2. Estrutura de Pastas por Episódio
- `output/episodio_01/roteiro.txt`
- `output/episodio_01/prompts/` (Cena 01, Cena 02, Cena 03)
- `output/episodio_01/audio/` (Locuções geradas)
- `output/episodio_01/video/` (Clipes animados)

## 3. Montagem
- Importar os clipes e áudios numerados para o editor (Google Vids / CapCut) e exportar em 1080p 16:9.
